# CHIPAKK Firestore Data Model Documentation

This document serves as the official schema definition for the CHIPAKK production database migration.

---

## 1. Schema Specifications by Collection

### admins
*   **Path**: `/admins/{uid}`
*   **Document ID Strategy**: Matches the Firebase Authentication `UID` of the admin.
*   **Required Fields**:
    *   `role`: `string` ("admin" | "super_admin") — Defines system permission level.
    *   `active`: `boolean` — Global toggle to disable credentials.
    *   `createdAt`: `timestamp`
*   **Control Type**: Admin-controlled; Server-generated `createdAt`.
*   **Relationships**: Linked to actions logged in `auditLogs`.

### users
*   **Path**: `/users/{uid}`
*   **Document ID Strategy**: Matches the Firebase Authentication `UID` of the customer.
*   **Required Fields**:
    *   `email`: `string`
    *   `createdAt`: `timestamp`
    *   `updatedAt`: `timestamp`
*   **Optional Fields**:
    *   `fullName`: `string`
*   **Subcollections**:
    *   `/users/{uid}/addresses/{addressId}`: Shipping addresses.
    *   `/users/{uid}/wishlist/{productId}`: Wishlist items.
*   **Control Type**: Customer-controlled (`fullName`, `email`); Server-generated (`createdAt`, `updatedAt`).

### products
*   **Path**: `/products/{productId}`
*   **Document ID Strategy**: Autogenerated string or slugified SKU.
*   **Required Fields**:
    *   `name`: `string`
    *   `description`: `string`
    *   `sku`: `string` (Base/fallback SKU)
    *   `price`: `number` (Base price, stored in Cents/Paise, e.g. 19900 = ₹199)
    *   `compareAtPrice`: `number` (Cents/Paise; 0 if no discount)
    *   `images`: `array` of `string` (URLs)
    *   `categoryId`: `string` (Refers to `/categories/{categoryId}`)
    *   `tags`: `array` of `string`
    *   `active`: `boolean` — Controls visibility on shop pages.
    *   `featured`: `boolean` — Controls homepage positioning.
    *   `options`: `array` of `objects` [Optional] — Defines option groupings for variants:
        *   `id`: `string` (e.g., "material")
        *   `name`: `string` (e.g., "Material")
        *   `values`: `array` of `objects` containing `id` (string) and `name` (string)
    *   `createdAt`: `timestamp`
    *   `updatedAt`: `timestamp`
*   **Control Type**: Admin-controlled; Server-generated (`createdAt`, `updatedAt`).
*   **Subcollections**:
    *   `/products/{productId}/variants/{variantId}`: Specific sellable SKU option combinations.

### variants
*   **Path**: `/products/{productId}/variants/{variantId}`
*   **Document ID Strategy**: 
    *   Standard products without options: `default`
    *   Products with options: Deterministic human-readable slug generated from normalized option selections (e.g., `material_glossy__size_2in`).
*   **Required Fields**:
    *   `variantId`: `string` (matches the Document ID)
    *   `options`: `map` — Key-value pairs matching selected options (e.g., `{"material": "glossy", "size": "2in"}`)
    *   `price`: `number` (Integer Paise/Cents, e.g. 19900)
    *   `sku`: `string`
    *   `stock`: `number` (baseline stock quantity)
    *   `reserved`: `number` (reserved units)
    *   `active`: `boolean`
    *   `createdAt`: `timestamp`
    *   `updatedAt`: `timestamp`
*   **Control Type**: Admin-controlled; Server-generated (`createdAt`, `updatedAt`); Transactional updates (`stock`, `reserved`).

### categories
*   **Path**: `/categories/{categoryId}`
*   **Document ID Strategy**: Autogenerated ID or URL slug.
*   **Required Fields**:
    *   `name`: `string`
    *   `slug`: `string` (Unique)
    *   `active`: `boolean`
    *   `createdAt`: `timestamp`
*   **Control Type**: Admin-controlled.

### orders
*   **Path**: `/orders/{orderId}`
*   **Document ID Strategy**: Autogenerated sequential alphanumeric ID (e.g., `CHP-YYYYMMDD-XXXX`).
*   **Required Fields**:
    *   `customerId`: `string` | `null` (linked to `/users/{uid}`, null for guest checkout)
    *   `customerEmail`: `string`
    *   `customerName`: `string`
    *   `items`: `array` of `maps` containing **historical/snapshot fields** to preserve transaction state:
        *   `productId`: `string`
        *   `variantId`: `string` (Matches the purchased variant, e.g. `default` or `material_glossy__size_2in`)
        *   `name`: `string` (at time of purchase)
        *   `sku`: `string` (at time of purchase)
        *   `price`: `number` (unit price at time of purchase, in Cents)
        *   `qty`: `number`
    *   `subtotal`: `number` (in Cents)
    *   `discountTotal`: `number` (in Cents)
    *   `shippingCharge`: `number` (in Cents)
    *   `totalPrice`: `number` (in Cents)
    *   `shippingAddress`: `map` containing `line1`, `line2`, `city`, `state`, `postalCode`
    *   `paymentMethod`: `string` ("Card" | "UPI" | "COD")
    *   `paymentStatus`: `string` ("pending" | "paid" | "failed")
    *   `fulfillmentStatus`: `string` ("Pending" | "Processing" | "Shipped" | "Delivered" | "Cancelled")
    *   `createdAt`: `timestamp`
    *   `updatedAt`: `timestamp`
*   **Optional Fields**:
    *   `couponCode`: `string`
*   **Control Type**: Customer-controlled (contact/address/payment selection); Admin-controlled (`fulfillmentStatus`, `paymentStatus`); Server-controlled (`subtotal`, `discountTotal`, `shippingCharge`, `totalPrice`, `items[].price`, `createdAt`, `updatedAt`).

### inventory (Deprecated)
*   **Path**: `/inventory/{productId}`
*   *Note*: This root collection is deprecated. All inventory (stock/reserved) for new and migrated items is now tracked directly at the variant document level `/products/{productId}/variants/{variantId}`.

### coupons
*   **Path**: `/coupons/{couponId}`
*   **Document ID Strategy**: Uppercase coupon code (e.g. `START10`).
*   **Required Fields**:
    *   `discountType`: `string` ("percent" | "fixed")
    *   `amount`: `number`
    *   `minOrderValue`: `number` (in Cents)
    *   `active`: `boolean`
    *   `startDate`: `timestamp`
    *   `endDate`: `timestamp`
*   **Control Type**: Admin-controlled; Server-validated.

### events
*   **Path**: `/events/{eventId}`
*   **Document ID Strategy**: Autogenerated ID.
*   **Required Fields**:
    *   `name`: `string`
    *   `type`: `string` ("drop" | "flash_sale")
    *   `startTime`: `timestamp`
    *   `endTime`: `timestamp`
    *   `discountPercent`: `number`
    *   `targetProducts`: `array` of `string` (Product IDs)
    *   `targetCategories`: `array` of `string` (Category IDs)
    *   `active`: `boolean`
*   **Control Type**: Admin-controlled.

### campaigns
*   **Path**: `/campaigns/{campaignId}`
*   **Document ID Strategy**: Autogenerated ID.
*   **Required Fields**:
    *   `title`: `string`
    *   `description`: `string`
    *   `bannerUrl`: `string`
    *   `targetUrl`: `string`
    *   `active`: `boolean`
*   **Control Type**: Admin-controlled.

### banners
*   **Path**: `/banners/{bannerId}`
*   **Document ID Strategy**: Autogenerated ID.
*   **Required Fields**:
    *   `imageUrl`: `string`
    *   `targetUrl`: `string`
    *   `order`: `number` (integer sorting field)
    *   `active`: `boolean`
*   **Control Type**: Admin-controlled.

### reviews
*   **Path**: `/reviews/{reviewId}`
*   **Document ID Strategy**: Autogenerated ID.
*   **Required Fields**:
    *   `productId`: `string`
    *   `customerId`: `string`
    *   `customerName`: `string`
    *   `rating`: `number` (1-5 integer)
    *   `comment`: `string`
    *   `status`: `string` ("pending" | "approved")
    *   `createdAt`: `timestamp`
*   **Control Type**: Customer-controlled (`productId`, `customerName`, `rating`, `comment`); Admin-controlled (`status`); Server-controlled (`customerId`, `createdAt`).

### siteSettings
*   **Path**: `/siteSettings/global`
*   **Document ID Strategy**: Singleton document named `global`.
*   **Required Fields**:
    *   `storeName`: `string`
    *   `maintenanceActive`: `boolean`
    *   `maintenanceMessage`: `string`
    *   `heroHeadline`: `string`
    *   `heroSubheadline`: `string`
    *   `announcementText`: `string`
    *   `announcementActive`: `boolean`
*   **Control Type**: Admin-controlled.

### shippingRules
*   **Path**: `/shippingRules/global`
*   **Document ID Strategy**: Singleton document named `global`.
*   **Required Fields**:
    *   `freeShippingThreshold`: `number` (stored in Cents, e.g. 30000 = ₹300)
    *   `standardFee`: `number` (in Cents, e.g. 5000 = ₹50)
    *   `enabled`: `boolean`
    *   `regionalOverrides`: `array` of `maps`
*   **Control Type**: Admin-controlled; Server-validated.

### auditLogs
*   **Path**: `/auditLogs/{logId}`
*   **Document ID Strategy**: Autogenerated ID.
*   **Required Fields**:
    *   `timestamp`: `timestamp`
    *   `actorId`: `string` (UID or "system")
    *   `actorEmail`: `string`
    *   `action`: `string`
    *   `details`: `map`
*   **Control Type**: Server-generated only. Customer writes/deletes are strictly denied.

## 2. LocalStorage to Firestore Mapping

| LocalStorage Key | Target Firestore Location | Description |
| :--- | :--- | :--- |
| `products` | `/products` (collection) | Catalog items |
| `categories` | `/categories` (collection) | Department layout |
| `site_settings` | `/siteSettings/global` (singleton document) | Configurable store titles/splashes |
| `events` | `/events` (collection) | Promotions/sales configuration |
| `coupons` | `/coupons` (collection) | Discount codes |
| `mock_orders` | `/orders` (collection) | Client-side fallback orders database |
| `audit_logs` | `/auditLogs` (collection) | System administrator access log |
| `chipakk_cart` | N/A (stays on client) | Kept as client-side temporary state |

---

## 3. Required Firestore Indexes

The following composite indexes must be defined in `firestore.indexes.json` to enable administrative query sorting:
1. **`products`**: `category` (Ascending) + `active` (Ascending) + `createdAt` (Descending)
2. **`orders`**: `customerId` (Ascending) + `createdAt` (Descending)
3. **`events`**: `active` (Ascending) + `endTime` (Ascending)
